## 📚 Описание проекта

**"Знание Севера"** - это комплексная web-система электронного дневника, предназначенная для автоматизации учебного процесса в образовательных учреждениях. Система предоставляет удобные инструменты для администраторов, учителей, учеников и родителей.

Это финальная версия проекта с полноценным PHP backend, структурированным кодом и расширенной функциональностью.

## 🚀 Установка и настройка

### 📋 Предварительные требования

- **PHP 7.4** или выше
- **MySQL 5.7** или выше (рекомендуется 8.0+)
- Web-сервер Apache или Nginx
- Современный браузер (Chrome, Firefox, Safari, Edge)
- Утилита `curl` для работы с API (опционально)

### 📥 Шаг 1: Клонирование репозитория

```bash
git clone https://github.com/razetka2010/znanie-severa-version-final.git
cd znanie-severa-version-final
```

### 🔧 Шаг 2: Настройка базы данных

1. **Создайте базу данных:**

```sql
CREATE DATABASE znanie_severa;
USE znanie_severa;
```

2. **Импортируйте схему базы данных:**

```bash
mysql -u root -p znanie_severa < database.sql
```

(файл `database.sql` должен быть в корне проекта)

### ⚙️ Шаг 3: Конфигурация

1. **Отредактируйте файл `config/database.php`:**

```php
<?php
$servername = "localhost";
$username = "root";
$password = "your_password";
$database = "znanie_severa";

// Создание подключения
$conn = new mysqli($servername, $username, $password, $database);

// Проверка подключения
if ($conn->connect_error) {
    die("Connection failed: " . $conn->connect_error);
}
?>
```

2. **Настройте права доступа к папкам:**

```bash
chmod 755 admin/ school_admin/ teacher/ student/
chmod 644 config/*.php includes/*.php
```

### 🌐 Шаг 4: Запуск сервера

**Вариант 1: Локальный PHP сервер**

```bash
php -S localhost:8000
```

Затем откройте: `http://localhost:8000`

**Вариант 2: Apache/Nginx**

Скопируйте папку проекта в корневую папку сервера (`/var/www/html` для Apache)

### 🔐 Шаг 5: Первый вход

По умолчанию создается учетная запись главного администратора:
- **Email:** admin@znanie-severa.local
- **Пароль:** admin123456

⚠️ **ВАЖНО:** Измените пароль при первом входе!

## 🔒 Безопасность

### Реализованные меры безопасности

✅ **Аутентификация**
- Использование хеширования паролей (bcrypt/argon2)
- Session-based аутентификация
- Защита от brute-force атак

✅ **Авторизация**
- Role-Based Access Control (RBAC)
- Проверка прав доступа на каждой странице
- Логирование действий администраторов

✅ **Защита данных**
- SQL-injection prevention (prepared statements)
- XSS protection (HTML escaping)
- CSRF protection (tokens)
- Шифрование чувствительных данных

✅ **Протоколирование**
- Логирование входов в систему
- Аудит изменения оценок
- История действий администраторов
